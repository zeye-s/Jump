EIGHTFOLD TERRAIN v1.16 — COMPACT ASSET EDITION

This edition retains the same v1.16 artwork; its files were reorganised without redrawing. Extract the whole ZIP, keeping the folder structure.

Use/ contains eight organised PNG sheets, one per theme. Use/Index.csv lists items and rectangles; Use/Mapping.json maps them to the original Content sheets. Do not mix coordinates between Use and Content. Native32 uses the documented 32px mask connections. The whole-stone source is a finite 768 x 576 world-domain field and needs the supplied selection rules; it is not an infinitely repeating tile.

Content/Texture/ holds the eight original, frozen-coordinate sheets required by the Godot project and metadata. Content/Metadata/terrain.json holds the terrain contract. Content/Layouts/ holds six editable layout presets; Content/Examples/ contains two illustrative assembled images, not separate assets.

Optional Godot example: import Content/project.godot in Godot 4.7.2, wait for imports, then run. Select a theme and preset. See Docs/Godot_Quick_Start.txt for controls. Python render tools in Content/Tools require Python, Pillow and NumPy.

The previous self-contained HTML catalog, saved collection/export UI, and 46 extra rendered example images are not included in this compact edition. Existing v1.16 Catalog R2 and Legacy downloads retain their previous features if still offered on the product page. No material was repainted.

Read Docs/Two_Routes.txt, Docs/LICENSE.txt and Docs/AI_Disclosure.txt. Nearest-neighbour filtering is recommended. This pack does not supply collision or navigation.

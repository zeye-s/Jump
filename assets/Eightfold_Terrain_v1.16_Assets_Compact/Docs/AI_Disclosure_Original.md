# AI disclosure

This collection contains generative-AI-assisted bitmap artwork. Each theme's source artwork was generated and edited separately using OpenAI's image generation tool. It is not entirely hand-drawn native pixel art.

The reusable atlases were assembled from those images through cropping, nearest-neighbor normalization, transparent compositing, and engine export. The 32 × 32 specification describes the exported grid; it does not mean that every original image was drawn pixel by pixel at that resolution.

The product documentation, packaging tools, export code, and gallery code were also developed with AI assistance. The original English edition retained existing artwork. Later 1.1 and 1.2 maintenance includes the pixel edits described below.

Previews display the delivered assets. They have not been enhanced through additional image generation. Tiles repeat by design because they are reusable components. Third-party reference images, discarded drafts, and the private authoring workspace are not included in this consumer download. Selected source images, prompts, and provenance records are retained by the publisher.

No claim of exclusivity or identical copyright status in every jurisdiction is made. Please read LICENSE.txt and the compatibility notes in README.md before choosing these assets for a project.

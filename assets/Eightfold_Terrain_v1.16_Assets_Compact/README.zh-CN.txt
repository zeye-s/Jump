八主题地形 v1.16｜精简素材版

本版保留原 v1.16 素材，不重画。请完整解压并保持目录结构。

Use/ 内是八主题的分类取用 PNG；Use/Index.csv 是素材名和矩形索引，Use/Mapping.json 对照旧版 Content 图集坐标。Use 与 Content 的坐标不可混用。Native32 按元数据中的连接规则使用；完整石路母面为有限 768×576 世界源域，需配合选择规则，不能当作无限无缝地砖。

Content/Texture/ 保留 Godot 工程和元数据所需的八张原坐标图集；Content/Metadata/terrain.json 是地形规则；Content/Layouts/ 有六个可编辑布局；Content/Examples/ 保留两张拼接效果图，不是独立素材。

可选 Godot 示例：在 Godot 4.7.2 中导入 Content/project.godot，等导入完成后运行，选择主题和预设。操作见 Docs/Godot_Quick_Start.txt。Content/Tools 内 Python 渲染工具需要 Python、Pillow 和 NumPy。

本精简版不再包含自包含 HTML 素材目录、清单导出界面及另外 46 张效果图。原 v1.16 Catalog R2 与 Legacy 下载若仍在商品页提供，保持原有功能。素材像素未重绘。

请阅读 Docs/Two_Routes.txt、Docs/LICENSE.txt 和 Docs/AI_Disclosure.txt。像素显示建议最近邻。素材不包含碰撞或寻路。
